# morfe.studio

Temporary "under construction" home for [Morfe Studio](https://morfe.studio) — branding, textile development, tech packs and websites for clothing brands.

A single static page served by GitHub Pages on the custom domain `morfe.studio`. It reuses the Bauhaus visual system from the [profile README](https://github.com/morfemartin): the MORFE logotype and the arched door cut from the Morfe seal, which opens onto "coming soon".

```bash
python3 -m http.server 8000   # preview locally at http://localhost:8000
```

Built by [Martin Alejandro Morfe Carballo](https://github.com/morfemartin).
